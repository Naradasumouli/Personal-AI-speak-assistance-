# Mama Bro AI Assistant

Mama Bro is a personal AI voice assistant running locally on Windows using:

- Ollama
- Qwen2.5 Coder
- Faster Whisper
- Edge TTS
- Python

The goal of this project is to build a real Jarvis-style AI assistant capable of:
- Voice interaction
- Local AI reasoning
- Browser automation
- Productivity assistance
- Coding assistance
- Memory system
- Agentic workflows
- Personal automation

---

# Features

## Current Features

- Voice input using Faster Whisper
- Voice output using Edge TTS
- Local LLM using Ollama
- AI conversations
- Date and time tools
- Open websites/apps
- Google search
- Speech interruption support
- Basic AI tool architecture

# Tech Stack

| Component | Technology |
|---|---|

| Speech-to-Text | Faster Whisper |
| Text-to-Speech | Edge TTS |
